# Leak-Watch---Machine-Learning-for-Water-Leak-Detection-Localization-and-Emergency-Dispatch
Machine Learning for Water-Leak Detection, Localization, and Emergency Dispatch.

An MS Data Science project. LeakWatch reads pressure from sensors on a water
network, detects and locates a leak, and dispatches the nearest repair crew.
Data is generated by simulation (EPANET / WNTR) and validated against the
open BattLeDIM benchmark.

## Structure
- data/       - generated sensor datasets
- notebooks/  - the Colab notebooks (simulation, models, evaluation)
- results/    - charts and results
